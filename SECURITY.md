# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

This project relies on PHREEQC as an external dependency. Security issues related to
PHREEQC itself should be reported to USGS.

For vulnerabilities in the automation scripts, please open a [security issue](https://github.com/songsongr/auto-phreeqc/security/advisories/new)
or contact the maintainers directly.

Please **do not** report security vulnerabilities through public GitHub issues.
