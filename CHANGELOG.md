## [0.2.0] - 2026-09-21

### Added

- Public `phreeqc_auto` Python package for input generation, execution,
  parsing, and visualization.
- Local browser Workbench for creating and inspecting simulations.
- Nine runnable reference examples spanning speciation, reaction, kinetics,
  and transport.
- User-facing guidance for Claude Code and Codex-compatible workflows.

### Changed

- Workbench, examples, and automated tests now use the public Python package.
- Documentation and examples no longer depend on private development files.
