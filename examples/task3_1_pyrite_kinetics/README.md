# 模拟: 黄铁矿氧化动力学 — 富氧环境 100 天演化

**日期**: 2026-05-12 | **数据库**: phreeqc.dat | **考题**: 3.1

## 模拟条件

| 参数 | 值 | 说明 |
|------|-----|------|
| 初始溶液 | pH 7.0, pe 4.0, 纯水 + K/Na/Cl 各 0.1 mmol/L | 中性富氧水 |
| 黄铁矿 (Pyrite) | FeS₂, 0.5 mol (~60g) | KINETICS 动力学溶解 |
| 速率方程 | Williamson & Rimstidt (1994) | R = k·A·[O₂]^0.5·[H⁺]^(-0.11)·(m/m₀)^(2/3) |
| 速率常数 k | 1.0×10⁻⁷ mol/m²/s | 25°C 文献值 |
| 比表面积 A₀ | 100 m² | 细磨粉末 0.5 m²/g × 200g |
| 氧化环境 | O₂(g) SI=-0.68 (大气平衡) | 开放系统 (EQUILIBRIUM_PHASES) |
| 二次矿物 | Fe(OH)₃(a) SI=0, Jarosite-K SI=0 | 允许沉淀，初始量=0 |
| 模拟时长 | 100 天 (8.64×10⁶ s, 18 步) | CVODE 积分器 |
| 时间步长 | 1h → 2h → 6h → 1d → 2d → 3d → 5d → 7d → 10d → 14d → 20d → 28d → 38d → 50d → 64d → 80d → 98d → 100d | 对数递增 |

## 关键结果

1. **pH 崩溃**: 7.0 → 3.07 (1h) → 2.15 (1d) → 1.46 (10d) → **1.03 (100d)**
   — 黄铁矿氧化 + Fe³⁺ 水解产酸，系统演化为极端酸性矿山废水 (AMD)

2. **黄铁矿 ~100% 溶解**: 100 天内 0.502 mol Fe 进入溶液，与初始 0.5 mol Pyrite 匹配
   — Fe:S 摩尔比严格保持 1:2，验证 FeS₂ 化学计量

3. **Jarosite-K 是唯一的二次沉淀相**: 在 pH 1.5-3 区间形成，K⁺ 耗尽后停止
   — KFe₃(SO₄)₂(OH)₆ 沉淀量 0.1 mmol (受 K⁺ 初始浓度限制)

4. **Fe(OH)₃(a) 和 Goethite 均未沉淀**: 极端低 pH 下 Fe³⁺ 氢氧化物不饱和
   — SI_Fe(OH)₃(a) = −4.98, SI_Goethite = +0.92 (100d)
   — Goethite 虽热力学过饱和但未列入 EQUILIBRIUM_PHASES 活动相

5. **O₂ 持续消耗**: 大气 O₂ 向溶液中补充 1.87 mol O₂ 用于黄铁矿氧化
   — 每 mol FeS₂ 需 ~3.75 mol O₂ (开放系统自动补充)

### charts/ph_vs_time.png
**类型**: 时间序列折线图 (single line)
**内容**: pH 随时间的演化轨迹 (100 天)
**X 轴**: 时间 (天), 0-100
**Y 轴**: pH
**解读**: 初始 1 小时内 pH 从 7.0 骤降至 3.07，这是反应最快阶段 — 中性 pH 下黄铁矿溶解速率高，且此时 O₂ 充足。随后 pH 渐近下降至 ~1.03，下降速率持续减缓。减缓原因：(1) pH 降低后 Fe³⁺ 水解减弱 (每 mol Fe³⁺ 水解产生 3 mol H⁺，但 pH<2 时 Fe³⁺ 主要溶解态)；(2) 黄铁矿表面随溶解减小 (m/m₀ 因子)。pH≈1 是理论下限，对应 0.5 mol FeS₂ 完全氧化 + 部分 Fe³⁺ 水解 + 极少量 Jarosite 沉淀的净产酸。

### charts/tot_fe_s_vs_time.png
**类型**: 时间序列折线图 (双线)
**内容**: 溶液中总 Fe 和总 S 浓度的累积曲线
**X 轴**: 时间 (天), 0-100
**Y 轴**: 浓度 (mol/kgw)
**线条**: Fe (蓝) 最终 0.502 mol/kgw, S (橙) 最终 1.004 mol/kgw
**解读**: Fe 和 S 浓度同步增长，S/Fe 比严格保持 2:1，完美符合 FeS₂ 化学计量。两者曲线形状几乎一致（仅差 2 倍因子），说明黄铁矿溶解时 Fe 和 S 均完全进入溶液。S 浓度达到 1.0 mol/kgw (96 g/L SO₄²⁻)，这是极端 AMD 特征 — 硫酸盐浓度远超天然水体。Fe 浓度 0.5 mol/kgw ≈ 28 g/L，若不稀释对水生生物致死的浓度。

### charts/si_vs_time.png
**类型**: 时间序列折线图 (多线)
**内容**: Pyrite, Fe(OH)₃(a), Goethite, Jarosite-K 的饱和指数时间演化
**X 轴**: 时间 (天)
**Y 轴**: 饱和指数 SI
**线条**:
- si_Pyrite: 持续 ≈ −220 — Pyrite 热力学极度不饱和，驱动力极强
- si_Fe(OH)₃(a): 从正变负，pH<2.5 后持续为负 — 非晶铁氢氧化物不饱和
- si_Goethite: 始终 > 0 (4.9 → 0.92) — 热力学上 Goethite 应沉淀，但在本模拟中未设为活动相
- si_Jarosite-K: 初始阶段 > 0，K 耗尽后逐渐降至负值 — Jarosite 沉淀消耗了 Fe³⁺ 和 SO₄²⁻
**解读**: Pyrite 的极低 SI (−220) 解释了其快速溶解的强烈热力学驱动力。Goethite 的持续过饱和表明：若系统封闭足够长时间 (数月到数年)，Goethite 会缓慢结晶沉淀，进一步降低溶解 Fe 浓度。但在 100 天尺度上，动力学限制使 Goethite 未能形成。

## 地球化学解读与 AMD 启示

### 反应序列
```
阶段 1 (0-1h):   FeS₂ + 3.75 O₂ + 0.5 H₂O → Fe²⁺ + 2 SO₄²⁻ + H⁺
                 Fe²⁺ + 0.25 O₂ + H⁺ → Fe³⁺ + 0.5 H₂O (快速, 高 pe)
                 Fe³⁺ + 3 H₂O ⇌ Fe(OH)₃(a) + 3 H⁺  (SI<0, 不沉淀)
                 
阶段 2 (1h-2d): 3 Fe³⁺ + K⁺ + 2 SO₄²⁻ + 6 H₂O → KFe₃(SO₄)₂(OH)₆ + 6 H⁺
                 Jarosite-K 沉淀 (K⁺ 耗尽即停止)
                 
阶段 3 (2d-100d): FeS₂ 继续溶解, 所有 Fe 和 S 累积在溶液中
                  pH 渐近 ~1.03 (H⁺ 产率减缓)
```

### 总反应计量 (100 天净结果)
```
0.5 FeS₂ + 1.87 O₂ + 1.0e-4 K⁺ + 0.5 H₂O
    → 0.5 Fe²⁺ + 1.0 SO₄²⁻ + 1.0 H⁺ (溶解)
    + 1e-4 KFe₃(SO₄)₂(OH)₆↓ + 6e-4 H⁺ (Jarosite)
    → 最终 pH ≈ 1.03
```

### 局限性与注意事项
1. **Goethite 未作为活动相**: 若将 Goethite 加入 EQUILIBRIUM_PHASES SI=0，会显著降低溶解 Fe 浓度 (Goethite 为热力学最稳定 Fe³⁺ 相)
2. **Fe²⁺ 氧化速率**: 本模拟通过 O₂(g) 平衡使 Fe²⁺→Fe³⁺ 氧化为瞬时过程，实际中低 pH 时 Fe²⁺ 氧化半衰期可达数天到数月
3. **单一速率定律**: Williamson & Rimstidt 定律适用于 25°C，不同温度需修正 Arrhenius 项
4. **无 Fe³⁺ 对黄铁矿的直接氧化**: 实际 AMD 中 Fe³⁺ 是比 O₂ 快得多的黄铁矿氧化剂 (Rimstidt & Vaughan, 2003)，本模型未包含此途径
