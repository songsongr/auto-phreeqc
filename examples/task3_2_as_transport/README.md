# 考题 3.2: 一维反应溶质运移 (As 穿透曲线)

**日期**: 2026-05-12 | **数据库**: phreeqc.dat (+ custom As master species)

## 模拟条件

- **柱体**: 1m 长沉积物柱，20 个单元格
- **初始条件**: 去离子水 (pH=7, pe=12)
- **入口溶液**: 1 ppm As(V) + 10 ppm Na + 15 ppm Cl (pH=7, pe=12)
- **流速**: 1 m/d → time_step = 0.05 day, 100 shifts (5 天)
- **弥散度**: 0.01 m (Pe_cell = 5)
- **示踪剂**: As(V) 定义为保守示踪剂 (AsO4-3 主物种，无吸附无反应)
- **Na/Cl**: 保守示踪剂对比

## 关键结果

| 指标 | 值 |
|------|-----|
| 入口 As 浓度 | 1.3348e-05 mol/kgw (1.00 ppm) |
| 入口 Na 浓度 | 4.3499e-04 mol/kgw (10.0 ppm) |
| 入口 Cl 浓度 | 4.2311e-04 mol/kgw (15.0 ppm) |
| 离子强度 | 4.89e-04 mol/kgw |
| 首次穿透 (C/C0 > 0.01) | ~step 17 (0.85 day) |
| 1 PV 时出口浓度 | 84% (step 20, 1.0 day) |
| 完全穿透 (C/C0 > 0.99) | ~step 28 (1.4 day) |
| Courant 数 | 1.0 (临界稳定) |
| 总运行时间 | 5 天 |

## 突破曲线特征

- **形状**: 经典的 S 形 (sigmoidal) 穿透曲线
- **峰值**: 1.3348e-05 mol/kgw (= 入口浓度，完全穿透)
- **中点**: C/C0 = 0.5 交点位于 ~step 19.5 (0.975 day ≈ 0.98 PV)
- **拖尾**: 对称 (非反应保守示踪剂，无吸附)
- **Na/Cl 一致性**: 三种示踪剂曲线完全重叠 (归一化后)

## 注意事项

1. **As 定义**: phreeqc.dat 不含 As 主物种，需在输入文件中手动定义 `SOLUTION_MASTER_SPECIES` 和 `SOLUTION_SPECIES`
2. **Courant 稳定性**: Courant=1.0 为临界值，更大值会导致数值振荡。安全范围: Courant ≤ 0.5-1.0
3. **弥散度**: 0.01m 在 20 cells/1m 柱体中给出 Pe_cell=5，突破曲线有适度展宽
4. **反应性**: 本模拟为保守示踪剂测试。实际 As 在含铁矿物表面有强吸附，需添加 SURFACE 络合模型
