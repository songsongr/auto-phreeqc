# 考题 1.2: 方解石饱和指数 (Calcite SI)

## 问题描述
**输入**: Ca²⁺ = 80 mg/L, 总碱度 = 200 mg/L (as CaCO₃), pH = 7.2
**计算**: 对方解石 (Calcite, CaCO₃) 的饱和指数 (SI)

## 参数解析

### 碱度单位转换
```
Alkalinity = 200 mg/L as CaCO₃
CaCO₃ 当量质量 = 50.045 g/eq (100.09 g/mol / 2 eq/mol)
Alkalinity = 200 / 50.045 = 4.0 meq/L
```

### 电荷平衡
```
Ca²⁺: 80 mg/L = 80/40.078 = 2.0 mmol/L = 4.0 meq/L
碱度: 4.0 meq/L
电荷差: 4.0 - 4.0 = 0.0 meq/L → 完美平衡
```

## PHREEQC 输入

```
SOLUTION 1
    units mg/L
    temp 25.0
    pH 7.2
    pe 4.0
    density 1.0
    Ca 80
    Alkalinity 200 as CaCO3
```

关键语法: `as CaCO3` 后缀让 PHREEQC 自动将碱度值从 CaCO₃ 当量转换为摩尔浓度。

### 关键发现
1. **SI=0 交叉点 pH ≈ 7.1**: 在此 pH 以下方解石溶解，以上则沉淀
2. **变化率**: ~0.25 SI / 0.25 pH，方解石 SI 对 pH 高度敏感
3. **天然意义**: 这解释了为什么碳酸盐岩地下水通常 pH = 7.0-8.3

## Skill 薄弱点 & 修复

1. **`generate_solution_block()` 不支持 `as <unit>` 语法**
