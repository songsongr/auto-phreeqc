# phreeqc-auto 🔬

**Automated geochemical simulation workflows for PHREEQC**

[![CI](https://github.com/songsongr/auto-phreeqc-public/actions/workflows/ci.yml/badge.svg)](https://github.com/songsongr/auto-phreeqc-public/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://github.com/songsongr/auto-phreeqc-public/blob/main/LICENSE)
[![Python 3.9+](https://img.shields.io/badge/python-3.9%2B-blue.svg)](https://github.com/songsongr/auto-phreeqc-public/blob/main/pyproject.toml)

用自然语言描述地球化学模拟需求，工作流负责输入文件生成、PHREEQC 执行、输出解析与可视化。

## 快速开始

```bash
pip install numpy matplotlib pandas
export PHREEQC_EXE="/path/to/phreeqc.exe"
export PHREEQC_DATABASE="/path/to/phreeqc.dat"
```
